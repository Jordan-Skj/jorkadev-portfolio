# Polices locales

Les polices Inter et Space Grotesk sont déjà incluses au format WOFF2, plus léger pour le web :

- `Inter-Regular.woff2`
- `Inter-Medium.woff2`
- `Inter-SemiBold.woff2`
- `SpaceGrotesk-Regular.woff2`
- `SpaceGrotesk-SemiBold.woff2`
- `SpaceGrotesk-Bold.woff2`

Le navigateur utilise automatiquement une police système de secours si un fichier manque.
